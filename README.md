# Unsupervised-Learning-Challenge
This repository contains my submission for the Module 19 Challenge due on 3/13. All of the work present has been created by myself, Molly Pfefferkorn. My instructor, Dr. Carl Arrington, provided troubleshooting feedback during the designated office hours of this class. Data for this dataset was generated by edX Boot Camps LLC, and is intended for educational purposes only.
----------------
In this challenge, I applied unsupervised learning techniques using Python to analyze and cluster cryptocurrencies based on their 24-hour and 7-day price changes. After loading and exploring the crypto_market_data.csv in the Crypto_Clustering.ipynb file, I normalized the data using StandardScaler() and created a scaled DataFrame indexed by coin_id. I then used the elbow method to determine the optimal number of clusters (k) for the scaled data, visualizing inertia values to identify the best k. With this value, I applied the K-means algorithm to cluster the cryptocurrencies and visualized the results with hvPlot, mapping 24h and 7d price changes while highlighting each coin.

Next, I optimized clustering using Principal Component Analysis (PCA), reducing the dataset to three components and calculating the total explained variance. A new PCA-based DataFrame was created, and I repeated the elbow method to evaluate the ideal number of clusters again. The results were then compared to the earlier K-means clustering. Using the PCA data, I performed clustering, predicted new cluster labels, and visualized the results in a 2D scatter plot using the first two principal components.

To conclude the analysis, I created composite plots to compare elbow curves and clustering results from both the original scaled and PCA-transformed data. I addressed the impact of dimensionality reduction on clustering accuracy and interpretability.
